# Task: Package the MLX guess generator and record run versions

## Description

The Qwen 3.5 9B and Gemma 4 12B attacker results came from a script in a job temp folder, run in a throwaway environment. Move it into the repo with its own `uv` project, and make every run record what produced it.

## Acceptance Criteria
- [ ] `scripts/mlx_attack/` holds `gen_guesses.py`, a scoring wrapper around `attack.only_check_correctness`, and a `pyproject.toml` pinning `mlx-lm==0.32.2` (transformers 5).
- [ ] One command each to generate guesses and to score them, documented in a short README in that folder.
- [ ] Every result (anonymize, attack, guesses) records model repo and revision, mlx-lm version, claude CLI version and git commit.
- [ ] Re-running the scoring on the existing Qwen guesses gives the same level 1 rates (0.33, 0.63, 0.53, 0.42).

## Technical Details
- Source script: `/Users/nicolas/.claude/jobs/804d5e71/tmp/scripts/gen_guesses.py`.
- The generator uses the same lock file as `pii_benchmark/mlx_engine.py`.
- Version capture: `importlib.metadata.version("mlx-lm")`, `claude --version`, `git rev-parse HEAD`, model revision from the Hugging Face cache.

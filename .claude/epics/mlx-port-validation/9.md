# Task: Run levels 2 and 3 with the Claude attacker, 3 repeats

## Description

Extend the validation beyond the easy case. Anonymize levels 2 (hard) and 3 (implicit) with the 5 in-scope methods, attack with the Claude CLI attacker three times, and compare each rate with the paper's Table 1 "Hard" and "Implicit" columns.

## Acceptance Criteria
- [ ] Levels 2 and 3 anonymized with Presidio, GLiNER, Scrubadub, `llama_basic` and `llama_rescriber` (bf16 MLX for the Llama methods).
- [ ] Claude attack with `n_attack_repeats=3`; mean, spread and 95% interval per method and level.
- [ ] Each rate compared with Table 1; each gap outside the interval has a documented cause.
- [ ] Machine usage watched during the MLX runs (one model at a time).

## Technical Details
- Data: `benchmark/level_2.jsonl` and `benchmark/level_3.jsonl` from the Hugging Face dataset `imperial-cpg/rat-bench`.
- MLX anonymization: about 6 h per level for the two Llama methods.
- Claude calls: about 1,500 (5 methods × 100 profiles × 3 repeats × 2 levels), at most 8 at a time, with usage-limit waits.
- Level 3 texts are longer (1,500 to 2,000 words): check that no answer is cut at 4096 tokens in the call log.

## Dependencies
- #7 (MLX anonymizer validated).
- #8 (drift fixes applied before new runs).

## Effort Estimate
- Size: L
- Hours: 2 of work, about 12 h MLX and 1 h Claude of machine time

## Definition of Done
- [ ] Runs complete and scored
- [ ] Comparison with Table 1 recorded

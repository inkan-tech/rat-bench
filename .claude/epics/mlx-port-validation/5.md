# Task: Add the bf16 MLX anonymizer with a determinism check

## Description

The level 1 `llama_basic` texts were made with an 8-bit model, partly in batches, while the paper used full precision. Make the MLX anonymizer able to run the full-precision model `mlx-community/Meta-Llama-3.1-8B-Instruct-bf16`, one prompt at a time by default, and prove that MLX generation is deterministic.

## Acceptance Criteria
- [ ] `pii_benchmark/mlx_engine.py` knows the bf16 repo, selectable without code change (model version key or environment variable).
- [ ] The anonymizer path generates one prompt at a time unless batching is asked for, like the attacker (`MLX_ATTACK_BATCH`).
- [ ] A determinism script generates the same 5 level 1 prompts twice and reports byte-identical text.
- [ ] The one-model lock still refuses a second model process.

## Technical Details
- Model: 16 GB of weights; fits the 32 GB M1 Max alone.
- `LlamaAnonymizer.anonymize_batch` calls `engine.chat` with many conversations, which batches today; route it through one-at-a-time by default.
- Keep `MLX_BATCH_SIZE` and the batched path for opt-in use.

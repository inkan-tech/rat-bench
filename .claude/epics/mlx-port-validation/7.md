# Task: vLLM reference run on RunPod and MLX comparison

## Description

Run `llama_basic` with vLLM at full precision (the paper's engine) on the same level 1 data, attack the texts with Claude, and compare with the bf16 MLX result of task #6. This decides whether the MLX anonymizer is valid.

## Acceptance Criteria
- [ ] Hugging Face token checked against `meta-llama/Llama-3.1-8B-Instruct` before any spend (status codes only).
- [ ] Pod run through `scripts/runpod/launch.sh` with a 5 USD cap; pod deleted at the end.
- [ ] Claude attack of the vLLM texts done and scored.
- [ ] Report: rate on vLLM texts vs bf16 MLX texts (difference against the 95% interval half-width), and mean BLEU between the two text sets.
- [ ] Decision written: MLX anonymizer valid, or not valid with the next investigation step.

## Technical Details
- Pod command: `python -m pii_benchmark.anonymize --data_path=benchmark/vllm/level_1.jsonl --results_path=benchmark/vllm/level_1.jsonl --anon_methods=llama_basic --level=1 --scenario=medical --timing=1` (no Julia needed on the pod).
- Wrapper loads `RUNPOD_API_KEY` and `HF_TOKEN` from the root `.env` without printing them.
- First real use of `launch.sh`: watch it, and confirm pod deletion in the RunPod console.
- If MLX and vLLM differ: compare chat template, tokenizer, stop tokens and sampling (greedy) before anything else.

## Dependencies
- #6 (bf16 MLX result to compare against).
- `HF_TOKEN` in `/Users/nicolas/inkan/rat-bench/.env`.

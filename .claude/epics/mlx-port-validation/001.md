# Task: Audit code drift since the paper-era commit

## Description

The repo changed by about 1,800 added lines after commit `b8cface` (29 January 2026), the code version closest to the paper (arXiv 2602.12806v1). One change, the Scrubadub date-of-birth detector turned off in `1a80fe2`, moved level 1 re-identification from 37% to 66%. Find every other change that alters results, and decide for each one whether to restore the paper behavior or keep it.

## Acceptance Criteria
- [ ] `docs/drift-audit.md` lists every change in `git diff b8cface HEAD` over `pii_benchmark/anonymizers/`, `pii_benchmark/prompts.py`, `pii_benchmark/evaluation.py`, `pii_benchmark/uniqueness.py` and `pii_benchmark/utils.py`.
- [ ] Each change is classed as bug fix, new feature, or result-altering behavior.
- [ ] Each result-altering change has a decision (restore or keep) and a one-line reason.
- [ ] The re-identification rule is checked against the paper's Section 4: risk 1 on a recovered direct identifier, otherwise CorrectMatch correctness, threshold θ = 0.2.

## Technical Details
- Start from `git diff b8cface HEAD --stat`, then read each file's diff.
- Focus on the in-scope anonymizers: Presidio, GLiNER, Scrubadub, `llama_basic`, `llama_rescriber`.
- For prompts, compare the anonymizer and attacker prompts with Appendix B of the paper.
- For evaluation, check how guesses are matched to ground truth (string similarity, date parts, PUMS codes).
- Known decision: Scrubadub `DateOfBirthDetector` restored for English (`b0d4550`).
